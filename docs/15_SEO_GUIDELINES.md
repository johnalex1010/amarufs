# 15. Guía de SEO, GEO y AEO

## Objetivo

Crear páginas comprensibles para usuarios, motores de búsqueda y sistemas de respuesta asistida por IA.

## SEO técnico

Cada página pública relevante debe definir:

- title único;
- description clara;
- URL canónica cuando aplique;
- jerarquía correcta de encabezados;
- contenido indexable;
- enlaces internos útiles;
- metadata Open Graph;
- robots según intención de indexación.

## GEO

Para mejorar comprensión por modelos generativos:

- identificar entidades principales;
- explicar contexto de negocio;
- usar lenguaje claro y verificable;
- evitar contenido ambiguo;
- estructurar información por secciones;
- mantener datos actualizados.

## AEO

Para responder preguntas directas:

- incluir respuestas claras;
- usar listas y tablas cuando faciliten lectura;
- crear FAQs reales cuando aporten valor;
- evitar relleno;
- conectar intención de búsqueda con contenido útil.

## Datos estructurados

Usar schema cuando exista correspondencia real:

- Organization;
- WebSite;
- BreadcrumbList;
- Article;
- Product;
- FAQPage;
- LocalBusiness;
- Course;
- Event.

No inventar propiedades ni marcar contenido que no existe en la página.

## Criterios de aceptación

- Cada ruta pública tiene metadata adecuada.
- Existe una jerarquía semántica coherente.
- Los datos estructurados reflejan contenido visible.
- No se genera contenido duplicado innecesario.
- Las páginas importantes son rastreables.
