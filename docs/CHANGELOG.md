# Changelog

Todos los cambios relevantes del proyecto deben registrarse en este archivo.

El formato recomendado sigue una versión simplificada de Keep a Changelog y versionado semántico cuando el proyecto publique releases.

## Formato

```md
## [versión] - AAAA-MM-DD

### Agregado
- Nueva funcionalidad o documentación.

### Cambiado
- Ajustes sobre comportamiento existente.

### Corregido
- Bugs resueltos.

### Seguridad
- Cambios relacionados con seguridad.

### Removido
- Funcionalidad eliminada.
```

## [Sin publicar]

### Agregado

- Documentación base para proyectos Next.js en `docs/`.

## Reglas

- Registrar cambios visibles para desarrollo, operación o negocio.
- No registrar ruido de formato sin impacto.
- Incluir migraciones, cambios de variables y actualizaciones de dependencias.
- Mantener fechas en formato `AAAA-MM-DD`.
- Agrupar cambios por versión o entrega.
